Часть 8. Проведение сравнения

На основе проведённых тестов (Часть 7) были получены следующие результаты:

|   Запрос   | PostgreSQL | ClickHouse |
| :--------: | :--------: | :--------: |
| Фильтрация |  ~329 сек  |  ~2.7 сек  |
| Агрегация  |  ~295 сек  |  ~4.4 сек  |
|    JOIN    |  ~295 сек  |  ~9.3 сек  |

8.1 Анализ фильтрации

PostgreSQL: ~329 секунд
ClickHouse: ~2.7 секунды

ClickHouse быстрее примерно **в 100+ раз**

Выводы: 
- ClickHouse читает только нужный столбец, используется колоночное хранение, выполняется параллельно
- PostgreSQL выполняет Seq Scan (полный проход по таблице), обрабатывает данные построчно

8.2 Анализ агрегации

PostgreSQL: ~295 секунд
ClickHouse: ~4.4 секунды

ClickHouse быстрее **в ~60–70 раз**

Выводы:
- ClickHouse использует векторизированное выполнение, эффективные агрегатные функции
- PostgreSQL выполняет HashAggregate, работает медленнее на больших объёмах

8.3 Анализ JOIN

PostgreSQL: ~295 секунд
ClickHouse: ~9.3 секунды

ClickHouse быстрее **в ~30 раз**

Выводы:
- ClickHouse выполняет join в памяти, эффективно обрабатывает большие массивы данных
- PostgreSQL использует Hash Join, требует полного сканирования таблицы
