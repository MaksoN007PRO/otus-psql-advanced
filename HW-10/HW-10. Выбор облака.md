Сравнение Managed PostgreSQL: YC vs SberCloud:

| Параметр                 | Yandex Cloud                   | SberCloud (Cloud.ru)                              |
| ------------------------ | ------------------------------ | ------------------------------------------------- |
| Сервис                   | Managed Service for PostgreSQL | Evolution Managed PostgreSQL                      |
| Минимальная конфигурация | 2 vCPU / 4 GB RAM              | 1 vCPU / 1 GB RAM                                 |
| Доступ к БД              | Публичный IP у кластера        | Доступ только через отдельную ВМ в той же подсети |
| Подключение              | напрямую через psql            | через VM (bastion)                                |
| Latency                  | ~100–200 ms                    | ~150–250 ms                                       |
| Удобство интерфейса      | очень удобный                  | более сложный                                     |
| Итого за месяц           | **≈ 8200 ₽**                   | **≈ 1500 ₽**                                      |
