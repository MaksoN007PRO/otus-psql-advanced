Для тестирования использован набор данных Chicago Taxi Trips, размещённый в Google Cloud Storage.

## Тестирование производительности

После загрузки датасета были выполнены запросы различных типов для оценки производительности CockroachDB на большом объёме данных.

### Запрос COUNT

Для проверки скорости полного сканирования таблицы выполнен запрос подсчёта количества записей.

```
SELECT COUNT(*)FROM trips;
```

### Запрос GROUP BY

Для проверки производительности агрегирующих операций выполнена группировка данных.

```

```

Результат выполнения:

![](<images/Pasted image 20260610151720.png>)

CockroachDB корректно выполняет агрегацию и подсчёт статистики по группам.

### Запрос JOIN

Для оценки производительности операций соединения таблиц выполнен запрос с использованием JOIN.


В ходе выполнения работы был развёрнут экземпляр CockroachDB в облачной инфраструктуре Yandex Cloud и подготовлена тестовая база данных.
